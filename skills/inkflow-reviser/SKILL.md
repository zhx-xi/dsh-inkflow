# 修订 · 定向改写

修订是**外科手术**，不是重写。判断成功的标准：审校清单上的 S1 全修掉，S2 按作者取舍修掉，而全章读起来仍像同一个人写的。

## 输入

1. 待修正文。
2. 审校报告（含严重级与正文原句定位）。没有报告就先要一份，不要自己边读边改。
3. 作者取舍：哪些 S2 要修、哪些保留；作者若有“这版别动某段”，该段即为禁区。
4. 相关设定条目（修设定冲突时必须有原文依据）。

## 步骤

1. **排序**：S1 全做；S2 按作者取舍；S3 默认不动（避免把文风改成审校者的口味）。
2. **定范围**：每条问题先划最小改动面——一句、一段，还是一整个场景。能用一句修好的不许重写一段。
3. **改冲突不改事实**：与设定冲突时，优先改正文表述去贴合 canon；只有当 canon 本身有误（且作者确认）才动设定条目，并在报告里单列。
4. **补伏笔要回填**：为回收补埋设时，埋点放在本章前段自然的位置，不要新开一段“说明”。
5. **保持口吻**：改写段落沿用原段的句长节奏与用词层级；不要顺手把长句拆成短句、把书面语改成口语（那是润色的活）。
6. **对照交付**：逐条给 `问题 → 改动位置 → 改后原文 → 为什么这么改`；一次改动只解决一条问题，避免“一处大改顺带修了三条”。
7. **回归自检**：改完从头读一遍，检查改动处与上下句是否接得上、有没有制造新的时间/信息矛盾。

## 检查项

- [ ] S1 全部修掉，且每条都能在报告里指到改后原文
- [ ] 未授权改动的段落为零（作者禁区原样保留）
- [ ] 没有顺手改写无关段落（diff 面等于问题面）
- [ ] 改后仍满足本章字数与章末钩子要求
- [ ] 报告区分“已修”和“未修（原因）”，没有含糊其辞

## 常见坑

| 坑 | 后果 | 改法 |
|---|---|---|
| 借修订重写全章 | 作者认不出自己的稿 | 只改被点名的位置 |
| 为修一致性改设定 | canon 被悄悄改写 | canon 有误须作者确认 |
| 一条改动修三个问题 | 无法复核，回归难 | 一条一改 |
| 补伏笔时写解释段 | 读者被提前告知 | 埋进已有动作与对话 |
| 顺手润色 | 改动面失控 | 润色另走润色流程 |
