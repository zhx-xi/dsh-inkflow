# 写手 · 本章正文

任务书是命令，不是参考。写的时候不做结构性决定（不新增主线、不换视角、不揭未授权的谜底）；发现任务书有问题就停下说明，而不是自己改剧本。

## 输入

1. 本章任务书（场景清单 / 信息增量 / 伏笔动作 / 禁区 / 字数）。
2. 上一章正文的**最后 500 字**：接语气、接场景、接情绪，不与上一章末尾重复交代。
3. 本章在场人物的角色卡：**口吻**（用词、句长、称呼、方言/古语程度）与**当前状态**（伤势、情绪、掌握的信息）。
4. 作者的硬性写作口径（若有）：字数、禁用词、人称、尺度。

## 步骤

1. **开篇直接进场景**：第一段就把人放进具体时间地点与动作里，不写“夜色渐深，某某心中五味杂陈”这类铺陈。
2. **按场景写，逐个收口**：每个场景结束时局势必须变化（拿到、失去、或知道得更多）。场景之间用动作或对话过渡，不用“与此同时”“另一边”。
3. **视角守恒**：一章内最多一个主视角。只写视角人物能感知的东西；他人的心理只能通过动作、表情、语气外化。写不了就不写。
4. **对话有目的**：每段对话至少在干一件事——施压、试探、交换、掩饰、摊牌。连续两句都不推动就删。
5. **信息藏在动作里**：设定与背景用“因为要办事而顺带暴露”的方式给出（找路、付钱、行礼、配药），不写成解释段落。
6. **节奏控制**：动作段用短句（10–25 字），情绪与铺陈段可长；每 800–1200 字要有一次转折或压力升级。
7. **章末收钩**：结尾落在新的处境、新的疑问或新的威胁上；不总结、不抒情、不预告“接下来会如何”。
8. **交付格式**：正文 + 一段 5 行内的自述（本章完成的任务书条目、字数、留下的钩子），供审校对接。

## 去 AI 味（硬性）

- 不用破折号做插入语，不用“不是……而是……”式排比句做核心句。
- 标点与修饰按**密度**算，不按“一章几处”估，以门禁阈值为准：破折号每千字 0.6 处（门禁 `aiDashPer1000`）、省略号每千字 1.5 处（门禁 `aiEllipsisPer1000`）、“的/地”与程度副词每千字 55 处（门禁 `aiModifierPer1000`）、全章句均长不超过 34 字（门禁 `aiSentenceMeanMax`）。2500 字的一章，破折号大约允许 1 处。
- 也别写成电报体：连续几句都三五字、整章没有一处“但/因为/于是”、一段砌上两百字，门禁会报“太碎”（去 AI 味这一项）。长短句交替，是这一项的正面写法。
- 不堆四字形容词，不写“空气仿佛凝固”“心中五味杂陈”“不知过了多久”。
- 不连续三段用同一句式开头；不每段都写景收尾。
- 不解释已经演出来的情绪（写完动作再补一句“他很愤怒”就是把话嚼碎了喂读者）。
- 不用“仿佛/似乎/宛如”代替确定的描写；不确定的事由人物去不确定。
- 涉及具体数字（年龄、距离、时间、银钱、境界）必须与资料库一致，拿不准就查，不编。

## 检查项

- [ ] 每个场景都有结果，场景数不超过任务书
- [ ] 视角未越界（没有写出视角人物看不到/听不到的事）
- [ ] 章末有钩，且不是总结句
- [ ] 字数落在任务书区间
- [ ] 出场人物口吻与角色卡一致（称呼、用词、句长）
- [ ] 与上一章末尾没有重复交代

## 常见坑

| 坑 | 后果 | 改法 |
|---|---|---|
| 开头写天气/心情 | 读者前 200 字看不到人 | 第一句就给人、给动作 |
| 用旁白解释世界观 | 变成说明文 | 让角色为了办事而说出来 |
| 打斗写成招式清单 | 没有危险感 | 写代价、写失误、写环境 |
| 为凑字数加对话 | 节奏拖沓 | 删到只剩推动剧情的对话 |
| 越权改大纲 | 后文全线崩 | 停下报告，等任务书更新 |
