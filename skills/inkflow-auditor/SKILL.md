# 审校 · 四维一致性审计

只读交付：**不给改写稿**，给“问题清单 + 证据 + 严重级”。每条问题必须能指到正文的具体一句或资料库的具体一条，否则不许写进报告。

## 输入

1. 待审正文（完整一章）。
2. 本章任务书与其“本章承诺”（判是否写偏的唯一依据）。
3. 资料库：涉及人物的角色卡、相关世界观词条、活跃伏笔、时间线事件、章节目录（判断章号与前后文位置）。
4. 上一章与下一章的**任务书**（只看承诺，不读下一章正文，避免用未来信息判当前章）。

## 四个维度（各自独立过一遍，不许合并）

### D1 设定一致
- 人物：姓名用字、年龄、身份、能力/境界、伤残与随身物件。
- 世界：地理距离与行程耗时、势力归属、规则性设定（能不能飞、有没有电）、历法与时令。
- 判据：正文写法与资料库条目是否冲突；资料库空缺时标“资料库缺口”，不要凭记忆当设定。

### D2 时间线
- 本章内部时间是否顺流（有没有倒叙没说、三天过成一晚）。
- 与上一章末的时间点是否衔接；与下一章任务书的时间设定是否冲突。
- 明确的时间词（次日、半月后、开春）与事件间隔是否自洽。

### D3 人物一致
- 口吻：称呼、用词层级、句长是否与角色卡一致。
- 行为：是否与既定性格、当前伤势/情绪、当时掌握的信息一致。
- 信息边界：角色有没有说出他此刻不该知道的事（泄底是最常见硬伤）。

### D4 伏笔
- 任务书要求“埋/推/收”的动作是否真的发生，落在哪句。
- 是否出现了计划外的伏笔（意外埋下的线要标出来，别让它们在库里消失）。
- 回收是否有前置埋设；无埋设的“回收”是硬凑。

## 步骤

1. 先读任务书与“本章承诺”，再读正文——顺序反了会被正文带跑。
2. 四维各过一遍，逐条记：维度 / 严重级 / 正文原句（可定位）/ 冲突的资料库条目 / 一句话说明。
3. 严重级判定：
   - **S1 硬伤**：与设定直接矛盾、时间倒流、角色泄底、伏笔回收无埋设。必须改。
   - **S2 缺陷**：口吻轻微走样、信息给得太直、节奏塌陷。建议改。
   - **S3 建议**：可改可不改的表达与节奏选项。
4. 结算写偏：对照“本章承诺”逐条打勾/打叉，写偏超过一条即判本章不达标。
5. 输出报告：`S1 数量 / S2 数量 / 承诺达成 n/m`，再逐条列问题；结尾给“最小修复面”——只点名必须改的几处，不给全文改写方案。

## 检查项

- [ ] 每条 S1/S2 都能定位到正文原句
- [ ] 冲突项引用的是资料库条目，不是审校者的记忆
- [ ] 资料库空缺处标注为“缺口”，没有当成错误
- [ ] 报告里没有改写后的段落（只读交付）
- [ ] 承诺达成率算出来了

## 常见坑

| 坑 | 后果 | 改法 |
|---|---|---|
| 边读边改 | 交付变成第二版正文，作者意图被覆盖 | 只记录，不改写 |
| 拿后文设定判前文 | 误报“泄底” | 只用到本章为止的信息 |
| 只查错别字 | 结构性硬伤漏光 | 四维必须逐维过 |
| 严重级全标 S2 | 作者无法排序 | S1 必须能一句话说清为什么必须改 |
| 凭印象判设定 | 把审校者的想象当 canon | 查库，查不到就记缺口 |
