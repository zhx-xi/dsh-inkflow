# 架构师 · 本章任务书

你的产出不是正文，而是**一份让写手不需要再做决定的本章任务书**。判断标准只有一条：写手照着它能直接写，且不必回问“这章到底要干什么”。

## 输入（按顺序取，不要跳过）

1. **全书骨架**：整体大纲与当前卷大纲。只取本卷目标与本章在卷内的位置（起势/承转/高潮/余波）。
2. **前情**：上一章正文（读了再规划，不要只凭大纲推断前情）+ 上一章末尾三段的实际语气。
3. **在场资料**：本章涉及人物的角色卡（性格、口吻、当前状态、关系）、相关世界观词条、活跃伏笔清单。
4. **作者口径**：作者本次的原话（“这章要见血”“别写感情戏”）优先级最高；与大纲冲突时按作者原话，并在任务书里写明这处偏离。

## 步骤

1. **定本章的功能**：这一章结束时，读者的认知/情绪/局势必须发生哪一处不可逆的改变？写不成一句话就说明本章还不该写，回去合并或拆分。
2. **定冲突**：谁想要什么、谁挡着、代价是什么。没有阻力的章节只是过场，明确标成“过场章”并压到最短。
3. **排场景**（2–4 个）：每个场景写清 地点 / 在场人 / 目标 / 阻碍 / 结果（成、败、或换来更大麻烦）。场景之间必须有因果，不能只是时间先后。
4. **算信息增量**：本章向读者披露什么新信息（设定、人物底牌、势力动向），以及**刻意不披露**什么。禁止零增量章节。
5. **定伏笔动作**：逐条扫活跃伏笔，本章要“埋 / 推 / 收 / 不碰”。埋要写清埋法（谁的哪句话、哪个物件），收要写清回收点。没有动作的伏笔写“不碰”，别让它们自然消失。
6. **划禁区**：本章不出现什么（不出新人物、不揭某谜底、不打斗、不超过 3000 字）。禁区是给写手的硬约束。
7. **交接口**：给审校留三条“本章承诺”，后续用它判是否写偏。

## 检查项（交付前自检）

- [ ] 一句话说清本章不可逆的改变，且它由本章事件造成，不是叙述总结
- [ ] 每个场景都有阻碍；没有阻碍的场景已标注为过场并压缩
- [ ] 信息增量与伏笔动作逐条落到具体场景，不停留在“会提到”
- [ ] 任务书里没有“要有张力”“写出悲壮感”这类无法验收的词
- [ ] 与前情无硬冲突（时间、地点、谁在场、谁知道什么）

## 常见坑

| 坑 | 后果 | 改法 |
|---|---|---|
| 用大纲复述代替规划 | 写手把大纲写成流水账 | 任务书写“谁想要什么被怎么挡住”，不写“本章讲述…” |
| 一章塞三个高潮 | 每个都不够 | 只留一个主高潮，其余降为铺垫或后移 |
| 忘了人物知道什么 | 角色说出他不该知道的事 | 任务书里给每个在场人标“此刻知道/不知道” |
| 伏笔只在结尾提一句 | 后面没法回收 | 埋的时候写清触发条件与回收章节 |
| 不读前情就规划 | 接不上语气，重复上一章信息 | 先读上一章正文再动手 |
