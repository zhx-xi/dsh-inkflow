# 0027 外部参考的复用档位：方法论自写、数据表可引用、移植文件带出处

- 状态：已采纳
- 日期：2026-10-25
- 依据：[engineering-discipline §8](../constitution/engineering-discipline.md)、[AGENTS.md §10.6](../../AGENTS.md)
- 相关：#212（退化检测移植）、#214（阈值与类别启发）

## 背景

[engineering-discipline §8](../constitution/engineering-discipline.md) 的现行纪律是「**只学设计，不搬代码**」（N-06）。这条在对照代码型竞品时是够用的，但在对照 `zenstory-ai/oh-story-claudecode`（MIT，7982★，13 个写作 skill）时暴露了一个边界问题：

**「数据表」既不是设计，也不是代码。** 词表（禁用词、工程词、AI 腔句式）、阈值（复读 ≥12 字 ×3 次、句均长 ≤34、破折号 0.6/千字）、类别名单（22 类 AI 指纹）在对方仓库里是**在真实中文语料上标定出来的**。按旧纪律只能全部重写——而重写的不是文字，是**标定过程**：我们既没有那份语料，也没有那份人工标注预算（0.5.0 的误报口径只有 12 条人工标注，见 roadmap D5-2）。结果是「为了不抄，做出一份更差的表」。

反过来，若把「可以搬数据表」放宽成「可以搬文件」，就会滑向整包派生：对方 13 个 skill 共 4.3 MiB / 431 文件，搬进来会同时破坏零运行时依赖、包体积与「我们自己的工具面」三件事。

## 决策

按**内容性质**分三档，而不是按仓库性质一刀切。

| 档 | 内容 | 允许做什么 | 必须做什么 |
|---|---|---|---|
| **D1 方法论** | 流程、步骤、检查问句、取舍理由、交互设计 | 只借**结构与思路**，句子自己写 | 无法追溯具体句子；不写「照 XX 抄的」 |
| **D2 数据表** | 词表、阈值、类别/维度名单、正则片段 | **可引用具体内容**（值本身没版权增量，且标定成本高于重写） | 在**使用处**注明项目名 + 文件路径 + MIT；写出我们改了哪些值/删了哪些项 |
| **D3 代码** | 单个可移植的检测/解析实现 | **可移植单文件** | 文件头写明：来源仓库、原文件路径、许可（MIT）、改写了什么；**只允许单文件，禁止整目录复制** |

补充约束：

- **D4 许可证门槛不变**：D2/D3 只适用于 MIT / Apache-2.0 一类宽松许可。GPL 及非宽松许可**仍然只读行为**，不适用本 ADR 的 D2/D3（copyleft 污染与 AGPL 同理）。
- **D5 数字必须可追溯**：凡 D2 引用的阈值进入 `src/`，它必须能在 `gate-vocabulary.ts`（或同类单一来源文件）里找到，且注释写明出处。散落在多处 = 迟早漂移（本仓已有先例：#214 的破折号「一章 0–1 处」与实际 0.6/千字）。
- **D6 对照结论仍进 issue / PR**（D7 不入库）；本 ADR 只定**规则**，不记录某次对照的细节。

## 备选与取舍

| 备选 | 取/舍 | 理由 |
|---|---|---|
| **A. 维持「一律重写」** | 舍 | 对数据表而言，「重写」实际是把标定过程重做一遍，成本远超收益；而且我们更可能得到一份**没有语料支撑**的表——比引用一份有语料支撑的表更危险 |
| **B. 允许整包派生（MIT 合规）** | 舍 | 合法但有害：4.3 MiB / 431 文件会破坏零依赖与包体积；更关键的是会让我们放弃自己的工具面，退化成「别人的 skill 包 + 我们的壳」 |
| **C. 本 ADR 的三档** | **取** | 按内容性质分层：方法论自写保证「这是我们自己的产品」；数据表引用避免无意义的重复标定；代码只允许单文件移植并强制署名，把「到底抄了多少」变成文件头里的一句话 |

## 后果

- **好的一面**：D2/D3 让「借鉴」变成可审查的动作——reviewer 只需看使用处的署名与「改了什么」；不再出现「这条阈值哪来的」这种无解问题。
- **要付的代价**：每次 D2/D3 都要写署名与改动说明（约 5 行注释），并且**许可文本要随包走**（`package.json` 的 `files` 与新依赖、`check-package.mjs` 的清单都要同步——加文件不是零成本）。
- **审稿检查项加一条**：PR 里出现 `GATE_*` / 词表 / 阈值的新值时，必须能回答「自标还是引用」，引用则须有署名。
- 与本 ADR 冲突的旧表述（「只学设计，不搬代码」的绝对化读法）在 [engineering-discipline §8](../constitution/engineering-discipline.md) 同一提交内改为指向本 ADR。

## 验证

- 首个落地例：**#212**（移植 `check-degeneration.js` → 门禁第 8 项），文件头必须写明来源/许可/改写点；PR 正文给出「原文件 15,453 字节 → 我们的实现 N 行，改了什么」。
- 第二个落地例：**#214**（22 类 AI 指纹里的「太碎」方向 3 类），阈值必须自标并在注释里写明「引用类别启发、阈值为本项目语料标定」。
- 反例检查：**不做** DSH 宿主适配文档（对方已有 DSH 插件）——参考他们的做法，做我们自己的插件。
