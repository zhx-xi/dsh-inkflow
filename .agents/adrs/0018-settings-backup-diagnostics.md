# ADR-0018：设置的落点、备份的 ZIP 形态与诊断包的白名单

- 状态：已采纳（2026-10-24）
- 日期：2026-10-24

## 背景

#42 要三件在 0.4.0 之前完全不存在的能力：**设置页**、**诊断包**、**本地备份**。它们各自都会踩到一条已定的边界：

1. 插件只有一处自有数据目录（`$DSH_HOME/inkflow/`，[ADR-0005](0005-files-first-with-derived-index.md) / [ADR-0012](0012-plugin-private-state-dir.md)），而书是**作者自己的 git 仓库**——设置写进书里就会进 git，写进 `index/` 就会随重建消失。
2. 零运行时依赖：没有 `archiver`、没有 `jszip`。备份要产出**别人能打开**的压缩包，就得自己写容器格式。
3. 诊断包最容易被塞进不该出门的东西（正文片段、`.env`、`.credentials.yaml`、OVK 的机器私有 peer），而它是**要发出去**的（贴 issue、发给维护者）。

## 决策

### D1 设置写全局，身份写书

| 层 | 文件 | 谁写 | 内容 |
|---|---|---|---|
| 全局（插件级） | `$DSH_HOME/inkflow/settings.json` | #42 的设置页 | 共享库路径、语义检索开关、自动保存间隔、作者名、排除目录等**跨书**选项；`schemaVersion: 1` |
| 每书 | `<book>/inkflow.json` | 初始化向导 / 用户手改 | 身份与元信息：`title` / `author` / `projectId` / `schemaVersion` / `seriesId` |

两层**不镜像**：全局设置不复制进书，书里的身份也不写回全局。理由是 ADR-0005 的「一本书 = 一个 git 仓库」——把插件级偏好塞进每本书，会让同一个作者的每本书都携带一份他本机的路径。

### D2 读设置的语义：缺失给默认，非法就夹取或回退

沿用 `src/host/config.ts` 已有的风格（`promptBudgetTokens` / `promptTailChars` 都是 clamp）：文件缺失 = 默认值；字段缺失 = 该字段默认值；值越界 = 夹到边界；类型不对 = 回退默认。**任何情况下不因设置文件损坏而让插件不启动**——坏文件被读成默认值，并在诊断包里作为一条告警出现。

设置改动**即时生效**：所有读取点都在使用时读（`readSettings()`），不做进程内缓存，因此不需要「保存后重启」。

### D3 备份 = store-only ZIP（method 0）+ 自写 CRC32

- 容器：标准 ZIP（本地文件头 + 中央目录 + EOCD），每个条目 **method 0（stored，不压缩）**，CRC-32 用查表法自算。
- 落点：`$DSH_HOME/inkflow/backups/<bookSlug>-<YYYYMMDD-HHmmss>.zip`（`bookSlug` = 书的目录名，非法字符替换为 `-`）。
- 保留：默认 **5 份**，超出删最旧；`settings.json` 的 `backupKeep` 可改（1–50）。
- 为什么不用 deflate：自研 deflate 是几百行的压缩器加几百行的解压器，出错时坏的是**唯一一份备份**；小说正文压缩比高但备份是**安全网**，可读性（能直接用资源管理器打开、能用标准工具核对）比体积重要。一个 50 万字的书约 3–5 MB，store-only 完全可接受。

### D4 备份内容与排除项

| 包含 | 排除（默认） |
|---|---|
| 九个内容目录下的全部文件 | `index/`（派生物，重建即可） |
| `inkflow.json`、`.gitignore` | `.git/`（历史归 git 自己） |
| `chapters/**/index.json`（catalog 是结构投影，入库） | `.inkflow/`（回收站/备份/候选：安全网不该套娃） |

`.inkflow/trash/` 作为**可选项**（`includeTrash: true`）：想连误删一起带走时才勾。这条写进设置页的说明文字，不做默认。

### D5 诊断包的白名单（只写这些）

版本与构建戳、`engines` 实际值、平台与架构、Node 与 ICU（full/small）、索引元信息（`user_version` / `fileCount` / `entityCount` / 最近重建时间）、各域计数、工具清单（名字 + surface hash）、设置（**脱敏后**：路径替换为 `~/`，token 类字段打码）、日志尾部 N 行（默认 200）。

**绝不包含**：任何正文或设定文件内容、`.env`、`.credentials.yaml`、`.openviking/config.local.json` 内容（只报「是否存在 / peer 是否合法」）、作者的绝对路径（替换为 `~/…` 或 `<book>`）。

**补充（#43，ADR-0022 D2：超预算次数进诊断包）**：白名单加一项 `brief` —— `{ runs, overBudgetRuns, last: { overBudget, rungs, trimmed[], budgetTokens, tokens } | null }`。它只回答「本次上下文没装下时是哪几段付的钱」，`trimmed` 是**段 id**（不是段标题、不是正文），其余全是计数；`null` 表示本进程一次简报都没装配过（会话不在书里时的正常状态）。没有新增任何正文、路径或文件名。

### D6 恢复走与 #36 同一条纪律

恢复 = 把 zip 解开逐文件写回。写法上**先解到临时目录**，再按 [ADR-0015](0015-repair-and-migration.md) 的备份包纪律执行：逐文件核对「当前摘要 = 该文件在恢复前应有的摘要」，被外部改过的文件报冲突不覆盖；恢复完成后重建索引，并把「恢复了哪些文件、跳过了哪些」写进报告。原因很直接：备份是**别人的**（可能是三天前的），而书可能已经改了三天。

### D7 `projectId` 由初始化向导写入（关闭 Q12）

`inkflow.json` 增可选 `projectId`（uuid v4），由**初始化向导**写入；既有书缺失时保持缺失（`origin.projectId` 允许 `null`，[ADR-0007](0007-plugin-shared-library.md) C3 已写）。它**不参与门禁**，也不参与任何解析来源——只是共享库溯源用的一枚身份。

## 备选与取舍

| 方案 | 优点 | 代价 | 为什么没选 |
|---|---|---|---|
| 备份调用系统 `tar`/`7z`/PowerShell `Compress-Archive` | 零代码 | 平台依赖、错误面不可控、CI 上行为不同；ADSF 宿主里能不能起子进程也没保证 | 插件是零依赖的纯 JS，备份是安全网，不该依赖外部可执行文件 |
| 自研 deflate | 体积小 | 几百行压缩 + 几百行解压；损坏时坏的是唯一副本 | 收益是体积，代价是数据安全，方向反了 |
| 备份落书内 `index/backups/` | 跟书走、git 不管 | `index/` 缺失即重建、且只忽略 `*.db`（ADR-0012 背景） | 已经踩过一次：回收站放 `index/` 被否 |
| 设置写进每本书的 `inkflow.json` | 设置跟书走 | 插件级偏好污染每本书的 git | 与「一书一仓库自包含」冲突 |
| **全局设置 + store-only ZIP + 白名单诊断包**（选中） | 零依赖、可读、可核对；设置与书解耦 | 备份体积略大；诊断包要维护白名单 | — |

## 后果

| 收益 | 代价与对策 |
|---|---|
| 设置与书解耦，换机器只带走 `$DSH_HOME/inkflow/settings.json` | 多机不同步（明确接受：它不是作品数据） |
| 备份是标准 ZIP，任何工具能打开、能核对 | 体积约等于原书；对策：保留 5 份 + 可改 |
| 诊断包可以放心贴出去 | 白名单要随新功能维护；对策：诊断包生成器的每个字段都要有来源测试（用例断言「不含正文片段」） |
| 恢复不会覆盖作者三天后的新改动 | 冲突要人工处理；对策：报告逐条列出冲突文件与原因 |

## 验证

- `tests/zip.test.js`：store-only 往返（写→读→逐字节相等）、CRC32 与 `zlib` 的 `crc32` 对拍若干样本、外部工具兼容性（本机用 PowerShell `Expand-Archive` 打开一次，证据贴 PR）。
- `tests/settings.test.js`：缺失/损坏/越界/类型错四种输入各自的回退；写入后再次读取即时生效；不写进任何书。
- `tests/backup-zip.test.js`：备份内容集合 = D4 的包含减排除（集合比较）；保留 5 份时删最旧；恢复时被改过的文件报冲突且不覆盖；恢复后索引可重建。
- `tests/diagnostics.test.js`：白名单字段齐全；把正文片段、`.env`、`credentials` 放进书里后导出，断言包里**不含**它们（字符串搜索）。
